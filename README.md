# 🌐 Portfólio — Letícia Rebeka

Portfólio pessoal desenvolvido para apresentar minha trajetória como Desenvolvedora Full Stack, meus projetos, conhecimentos técnicos e certificados.

## ✨ Funcionalidades

- Globo 3D animado em canvas na seção inicial
- Alternância entre tema escuro e claro (salvo em localStorage)
- Menu mobile com hambúrguer animado
- Link ativo no menu conforme a seção visível
- Animações de entrada com ScrollReveal
- Layout totalmente responsivo (mobile-first)
